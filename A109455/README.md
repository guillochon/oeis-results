## What is counted

A *threshold function* of n variables is a Boolean function f(x) = [w_1 x_1 + … + w_n x_n ≥ t] for some real
weights w_i and threshold t; negative weights are allowed, and the two constant functions count. A109455 counts
them up to **permuting the variables** (the group S_n). The related sequences use larger groups: N (negating
variables), NP (permuting and negating variables) and NPN (also complementing the output).

## Method (A109455)

**Burnside.** a(n) = (1/n!) Σ_{σ ∈ S_n} F(σ), where F(σ) is the number of threshold functions f with f∘σ = f.
F(σ) depends only on the cycle type of σ (15 types for n = 7, 22 for n = 8, 30 for n = 9).

**Averaging lemma.** If f∘σ = f and (w, t) realizes f, then so does (w∘σ, t). The set of realizing (w, t) is
convex, so the average over the cyclic group generated by σ also realizes f, and its weights are constant on each
cycle of σ. So a σ-invariant threshold function depends only on the counts c_j = number of 1s among the variables
of cycle j, and

    F(σ) = number of threshold functions on the integer grid {0..l_1} × … × {0..l_k},

where l_1, …, l_k are the cycle lengths of σ. For σ = identity the grid is the cube {0,1}^n and F = A000609(n);
every other σ gives a grid of fewer dimensions.

**Counting threshold functions on a grid** (`engine.py`, and its Rust port in `rust/`). Reflecting an axis maps
threshold functions to threshold functions, so the count is a sum over positive functions (weights ≥ 0) of 2^(number
of axes the function depends on). Axes of equal length can be permuted, so only *regular* positive functions
(weights non-increasing within each group of equal lengths) are visited, each weighted by its orbit size. The
search decides the value at the grid points one at a time, in an order compatible with monotonicity and
regularity; a point forced by an earlier one needs no work, and otherwise both branches are tried, each kept only
if a linear program finds a separating (w, t). **Every counted function is therefore certified by an explicit
weight vector** (the logs report `bad = 0`, the number of functions whose certificate failed a re-check). All
arithmetic on the counts is exact.

For σ = identity the regular positive functions on the cube are one per NP class, so this one grid also gives
A000617(n) (the number of regular positive functions), A002078(n) (the number of positive functions), A000609(n)
(all functions) and A001532(n) (the regular positive functions that are self-dual).

### Identities used for the derived terms

Every threshold function depends on a unique set of variables (its essential variables), and on them it is a
threshold function depending on all of them (fix the other variables at 0). Conversely, a threshold function of
k variables, viewed as a function of n ≥ k variables, is still a threshold function. Choosing which k of the n
variables are essential gives

    (1) A000609(n) = Σ_{k=0..n} C(n,k) A000615(k),  so  A000615(n) = Σ_{k=0..n} (-1)^(n-k) C(n,k) A000609(k).

The second form is the formula already in A000615. In the same way, writing e(k) = A002079(k) for the number of
positive threshold functions depending on exactly k variables,

    (2) A000615(n) = 2^n A002079(n)  and  A002078(n) = Σ_{k=0..n} C(n,k) A002079(k).

For (2): a function depending on all n variables is monotone in each of them, increasing or decreasing, so it is
obtained from exactly one positive function by negating exactly the variables in which it decreases, and the 2^n
choices give 2^n different functions. Combining (1) and (2), A000609(n) = Σ_k C(n,k) 2^k e(k), hence
Σ_k C(n,k) A000609(k) = Σ_j C(n,j) 2^j e(j) Σ_k C(n-j,k-j) = 2^n Σ_j C(n,j) e(j), that is

    (3) A002078(n) = 2^(-n) Σ_{k=0..n} C(n,k) A000609(k)

(the "BinomialMean transform of A000609" noted in A002078 is therefore an identity). Splitting classes by the
number of essential variables gives, for n ≥ 1,

    (4) A000619(n) = A000617(n) - A000617(n-1)  and  A001530(n) = A001529(n) - A001529(n-1).

Finally,

    (5) A001529(n) = (A000617(n) + A001532(n)) / 2.

Proof of (5): complementing the output (f → ¬f) maps threshold functions to threshold functions and commutes
with permuting and negating variables, so it acts on the NP classes as an involution, and the NPN classes are its
orbits. By Burnside for a group of order 2, A001529(n) = (A000617(n) + m)/2, where m is the number of NP classes C
with ¬C = C. It remains to show that ¬C = C exactly when C contains a self-dual function (f(x) = ¬f(¬x)), so that
m = A001532(n). Let f be the regular positive function in C, and let f^d(x) = ¬f(¬x) be its dual, which is again a
positive threshold function. ¬f is f^d with all variables negated, so ¬C is the class of f^d, and ¬C = C if and
only if f^d = f∘π for some permutation π. Every member of C has the form h = f∘π∘ε (π a permutation, ε a set of
negations), and its dual is f^d∘π∘ε, so h is self-dual if and only if f^d = f. So it suffices to show that
f^d = f∘π implies f^d = f. Order the variables by influence: i ≽ j if switching a 1 from x_j to x_i never turns f
from 1 to 0. For a threshold function with non-increasing weights this order is total and is 1 ≽ 2 ≽ … ≽ n, and
taking duals preserves it. So f∘π, which equals f^d, has the same order as f; hence π maps every block of
equally influential variables to itself. Variables in such a block are interchangeable in f, so f∘π = f, and
f^d = f.

The proof of (5) can also be checked by brute force for small n: this program counts the NP classes fixed by
complementing the output and the NP classes that contain a self-dual function. Save it in this folder (it uses
`bruteforce.py`) and run it; it prints `n, A000617(n), fixed classes, classes with a self-dual function`, and both
of the last two columns are A001532(n) = 0, 1, 1, 2, 3, 7 for n = 0..5 (2 s).

```python
from itertools import permutations
from bruteforce import all_threshold

for n in range(6):
    N, F = 1 << n, [int(T) for T in all_threshold(n, 9)[1]]   # all threshold functions (truth tables)
    full = (1 << N) - 1
    maps = [[sum(((x >> i) & 1) << p[i] for i in range(n)) ^ m for x in range(N)]
            for p in permutations(range(n)) for m in range(N)]  # all permutations and negations
    act = lambda T, pm: sum(((T >> pm[x]) & 1) << x for x in range(N))
    canon = {}
    for T in F:
        if T not in canon:
            orbit = {act(T, pm) for pm in maps}
            canon.update(dict.fromkeys(orbit, min(orbit)))
    classes = set(canon.values())
    fixed = sum(canon[c ^ full] == c for c in classes)
    negall = [x ^ (N - 1) for x in range(N)]
    selfdual = {canon[T] for T in F if T ^ full == act(T, negall)}
    print(n, len(classes), fixed, len(selfdual))
```

### What is being counted
A *threshold function* is f(x) = [w_1·x_1 + … + w_n·x_n ≥ t] for some real weights w and threshold t. Negative weights are allowed. Examples: AND, OR, majority, x_1 ∧ ¬x_2.
We count them up to **renaming variables only** (the group S_n); negating variables is not allowed.

### Why the listed a(6) = 590440 is impossible
- A000617(6) = 1113 is the number of classes up to renaming **and negating** variables. That group is bigger than S_n by a factor of 2^6 = 64.
- Each class of the bigger group splits into at most 64 classes of S_n (index argument).
- Therefore **a(6) ≤ 64 × 1113 = 71,232**.
- Lower bound: a(6) ≥ A000609(6)/6! = 15,028,134/720 ≈ 20,872.
- Sanity check on the other terms: a(5) = 1720 fits [94572/120 ≈ 788, 32 × 119 = 3808]. a(4) and a(3) fit their windows too.

The only escape would be if A109455 and A000617 counted different universes of functions, but both say "threshold functions of n variables". This is worth reporting as an OEIS correction together with a freshly computed correct value.

### How the known terms were probably computed
Knuth probably generated all threshold functions and reduced them by symmetry, which is fine up to n = 6 (15 million functions). For n = 7 there are 8.4×10^9 labeled functions, and for n = 8 there are 1.76×10^13.

### The clever idea: Burnside plus "threshold functions on a grid"
Burnside's lemma: a(n) = (1/n!) Σ_{σ ∈ S_n} Fix(σ), where Fix(σ) = # threshold functions with f∘σ = f. Only the cycle type of σ matters: 15 types for n = 7, 22 for n = 8.

**Key lemma (averaging):** if f∘σ = f and w separates f, then w∘σ also separates f. The set of separating (w,t) is convex, so the average over the cycle group separates f too. Hence **a σ-invariant threshold function always has weights that are constant on each cycle of σ**.

So if σ has cycles of lengths ℓ_1..ℓ_k, a σ-invariant threshold function depends only on the counts c_j = (number of 1s in cycle j) ∈ {0..ℓ_j}. It is a threshold function on the **grid** G = {0..ℓ_1} × … × {0..ℓ_k} ⊂ R^k:

    Fix(σ) = number of linearly separable 0/1 labelings of the grid G_λ   (λ = cycle type)

- σ = id: the grid is the cube {0,1}^n, so Fix = A000609(n), already known.
- Every other σ has k < n dimensions, which is a strictly smaller and easier problem.
- The hardest non-identity class is a single transposition: k = n−1 dimensions with 3·2^(n−2) points.

Counting separable labelings of a point set means counting the regions of a hyperplane arrangement in (w,t)-space, one hyperplane per point. Methods:
- [ ] Incremental region enumeration, adding one point at a time. This is the standard threshold-function enumeration algorithm, adapted to grids.
- [ ] Zaslavsky's theorem: regions = |χ(−1)|, where χ is the characteristic polynomial, computed via the intersection lattice or the Athanasiadis finite-field method.
- [ ] Reuse known results. Grid threshold functions ("threshold functions on k-valued logic / digital halfplanes") have their own literature, and some counts may already exist.
